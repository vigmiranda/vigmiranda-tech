# Vigmiranda.Tech

Portfolio estático de **Vitor Gomes Miranda** — software engineering, arquitetura e produtos.

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Vercel (Hobby) — import do repo `vigmiranda/vigmiranda-tech` ou:

```bash
vercel --prod
```
